📋 Class Design Worksheet — Barangay Services

OOP I · Transfer practice: same design moves, new domain. Answers go in the boxes — this worksheet is yours, no grading.

The Brief

The barangay secretary wants a small system to track residents who request services (barangay clearance, certificate of indigency, letter of endorsement). Each resident has a name, purok, and senior-citizen flag. Each request is made by ONE resident, has a type, a date, and a status. The secretary should be able to record a new request, mark one claimed (only from ready), and list a resident's requests. Seniors get priority numbering.

📌 Method reminder: nouns in the brief are class candidates · verbs the secretary does are method candidates · "has-a / made-by" phrases are relationships.

3 — Spot the invariant

The brief says a request can be marked claimed only from ready. That is an invariant — a rule that must always hold.
