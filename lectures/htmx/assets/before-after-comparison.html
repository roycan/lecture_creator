🧠 Key Insight: Both approaches produce the same visible result. The difference?

  • Manual fetch(): You write ~25 lines of imperative JavaScript — fetch(), .json(), forEach, createElement, appendChild.
  • htmx: You add one HTML attribute to a button. The server (or in this demo, an intercept handler) returns HTML, and htmx swaps it into the DOM.
