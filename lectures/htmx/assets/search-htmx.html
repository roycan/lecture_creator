🧩 htmx Attributes Used

hx-get="/search"

Sends a GET request to /search?q=… whenever triggered.

hx-trigger="keyup changed delay:300ms"

Fires after the user stops typing for 300ms (debounce). Only fires when the value actually changed.

hx-target="#results"

The HTML response from the server replaces the element.

hx-swap="innerHTML"

Replaces the inner content of the target (keeps the target element itself).

hx-indicator="#spinner"

Shows the ⏳ spinner element while a request is in flight.

✅ Zero JavaScript

Everything you see — debounced input, table updates, counters — is driven entirely by htmx attributes in the HTML.

📊 Before (ajax-fetch) vs Now (htmx)

Before: ajax-fetch

~12 lines of JavaScript

// Manual debounce
let timer;
input.addEventListener('input', () => {
  clearTimeout(timer);
  timer = setTimeout(async () => {
    const res = await fetch('/search?q=' + input.value);
    const data = await res.json();
    // Build HTML manually
    let html = '';
    data.forEach(o => {
      html += `${o.name}…`;
    });
    tbody.innerHTML = html;
  }, 300);
});
